Live Mutinynet path

This path is not a memory-only simulation. It expects three reachable LND REST endpoints: Agent, Gateway, and Merchant. The Gateway creates an incoming hold invoice; the Agent pays it; the Gateway pays the Merchant invoice; the observed preimage settles the Agent-side hold invoice; the Agent decrypts the response locally.
